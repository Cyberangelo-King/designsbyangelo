# Angëlo — Visual Practice

An art-directed graphic design portfolio by Angëlo (Faith Akinola Boyejo), based in Lagos, Nigeria.

## Portfolio
- 10 selected works with individual case-study pages and concise project stories.
- 20 visual studies exploring Swiss grid, Memphis, brutalism, Bauhaus, typography, colour, rhythm and composition.
- A consistent portfolio identity with individual art direction for each project.
- USD starting-rate card, terms-and-conditions note, process and design principles.
- A guided project enquiry builder that prepares an email; no contact form.
- 31-page downloadable editorial PDF.

## Motion and interaction
Framer Motion is pinned to 12.23.24 and loaded as a progressive enhancement. It animates the hero, orbital mark and scroll reveals. A Lottie orbital mark is loaded progressively through Lottie Web. CSS transitions, responsive fallbacks and reduced-motion support keep the experience usable if a motion library cannot load or a visitor requests reduced motion.

## SEO and performance
Page-specific titles and descriptions, canonical URLs, Open Graph and Twitter metadata, JSON-LD, sitemap, robots rules and llms.txt are included. Core artwork is vector SVG. Static assets use long-lived cache headers.

## Run locally
This is a static HTML/CSS/JavaScript/SVG site. No package installation or build command is required. Serve the repository root from a local static server, or deploy it directly.

## Connect to Netlify
The existing Netlify site was originally created as a manual drop. To enable continuous deployment from this repository:
1. Open https://app.netlify.com/projects/designsbyangelo.
2. Go to Project configuration → Build & deploy → Continuous deployment.
3. Choose Link repository, authorize GitHub if prompted, and select Cyberangelo-King/designsbyangelo.
4. Set production branch to main, publish directory to ., and leave the build command empty.
5. Save. Future pushes to main will trigger production deployments.

The repository includes netlify.toml; .netlify/ is excluded in .gitignore.
