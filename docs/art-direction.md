# Angëlo — Art direction

Palette: ink, warm paper, cobalt, vermilion and acid-lime accents. Typography: DM Sans, DM Mono and Playfair Display.

Principles: hierarchy, alignment, proximity, repetition, rhythm, contrast, scale and negative space. Establish the system, then interrupt it with intent.

Motion: pinned Framer Motion 12.23.24 as progressive enhancement; CSS and reduced-motion fallbacks; Lottie orbital mark.

Each project has its own art direction inside a consistent portfolio shell. Concepts and personal projects are credited accurately.
